Cache key convention

Tenant isolation rule

Every DB query must include eq(table.tenantId, tenantId). tenantId is always sourced from JWT (req.tenantContext.tenantId) — never from request body. Enforced by resolveTenant middleware.

Migration workflow

1. Edit src/db/schema.ts 2. pnpm db:generate ← drizzle-kit 3. Review drizzle/*.sql 4. pnpm db:migrate ← local apply // NEVER use drizzle-kit push in prod // Migrations run at deploy via migrate cmd

Security Architecture

Encryption at rest — AES-256-GCM

// src/lib/encrypted-column.ts export encryptField(plaintext: string): string // AES-256-GCM: 96-bit IV per encrypt // Format: base64(iv || ciphertext || authTag) export decryptField(ciphertext: string): string export hashForSearch(plaintext: string): string // HMAC-SHA256 — deterministic, non-reversible // Used for phone number lookup without decrypt
Protected fieldMethodSearchable?
Patient full nameAES-256-GCMNo
Patient phone numberAES-256-GCM + HMAC hashYes (hash lookup)
Patient notesAES-256-GCMNo
Caller number (call)AES-256-GCM + HMAC hashYes (hash lookup)
Intent summaryAES-256-GCMNo
Transcript summaryAES-256-GCMNo

Transport security

  • TLS 1.3 enforced on all endpoints via nginx
  • Let's Encrypt certificates (auto-renewed via certbot container)
  • WebSocket connections (Twilio media stream) over WSS
  • Strict CORS — origin whitelist only, no wildcard
  • HSTS, X-Frame-Options, X-Content-Type-Options headers set

6
Authentication & Middleware Stack

Auth flow

1. Login: email+password → bcrypt verify
2. TOTP MFA check (authenticator app)
3. Issue: JWT (access, 15 min) + refresh token (httpOnly cookie)
4. Every API request: authenticateJwt → resolveTenant
5. req.user: { userId, tenantId, role } — no email in token

JWT payload

// req.user injected by authenticateJwt middleware { userId: "uuid", tenantId: "uuid", // NOT from body role: "admin" | "staff" } // email is NOT in the token // fetch via authService.getUserAccountInfo()

Middleware chain (all protected routes)

authenticateJwt // verify + decode JWT resolveTenant // pin tenantId from token rateLimiter // per-IP + per-tenant limits validate({body}) // Zod schema validation routeHandler // business logic req.audit?.() // append to audit log

Rate limiting

ModuleLimitWindow
patients120 req60 s
auth (login)10 req60 s
general API300 req60 s

Audit log is append-only. Every call to req.audit?.() writes a timestamped record with action, entityType, userId, and tenantId. Retained 7 years; no UPDATE or DELETE is ever issued against this table.

8
Observability Stack

Tracing

OpenTelemetry SDK → OTLP → Datadog Agent (:4318). All BullMQ jobs carry OTel spans. Twilio + AI calls traced end-to-end.

Logging

Pino JSON logger. dd.trace_id / dd.span_id injected into every log line. PII fields redacted before emission.

Metrics

Prometheus endpoint + Datadog custom metrics. Business events (bookings, escalations, costs) tracked as distribution metrics.

Health checks

GET /health reports DB, Redis, worker, and media-stream status. Used by Docker Compose healthcheck and nginx upstream probe.
